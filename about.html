关于

你好，我是拾光（GitHub @cxjcom，这是示例介绍，改成你自己的故事）。 一个喜欢写代码、读闲书、记录生活的人。白天写前端，晚上写博客，周末在山里或书里。

这座小站是 2026 年 10 月上线的，零依赖纯静态：没有框架、没有构建步骤， 手写 HTML / CSS / JavaScript，托管在 GitHub Pages 上，用 Git 管理每一个版本。 选这个方案的理由很朴素——能持续写十年，比技术栈先进重要得多。
