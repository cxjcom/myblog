后台控制台 私密空间 ↗仅站主使用

🔐 站主登录

输入管理密码进入后台，可修改前台展示的资料、文章、相册与音乐。

在线上站点（GitHub Pages）修改？展开设置 GitHub Token

在本地 127.0.0.1:8080 修改无需 Token（自动提交推送）；在 cxjcom.github.io 上修改需要具备本仓库写入权限的 Personal Access Token，只在本次会话内使用。

个人资料 data/profile.json

文章管理 data/posts.json

这里管理的是「自定义文章」（会与 posts/ 目录里的内置示例文章合并展示）。新建后填好正文保存即可发布。

相册管理 data/album.json

上传的图片会存入仓库 assets/img/gallery/ 并自动推送。

心情签到 data/mood.json

先在下方选一个表情，再点月历里的日期打上/取消心情。改完点保存。
