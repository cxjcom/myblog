你好，世界：我的博客正式开张

2026-10-24 约 4 分钟 1500 字 拾光

花了几个晚上，这座小站终于上线了。这是第一篇文章，写给偶然点进来的你，也写给未来回头看的我——关于它为什么存在，以及我想用它做什么。

为什么是现在？

「搭个博客」这个念头，在我脑子里住了很多年。每次看到别人稳定更新十年的个人站，我都会羡慕一阵，然后以「太忙了」「等有空再说」搪塞过去。

真正让我下决心的是两件小事。一是我翻找三年前写过的一段技术笔记，发现它散落在某个已经停运的平台上，再也找不回来了；二是我意识到，在社交平台里，我写下的东西被算法切割、排序、夹在广告中间，阅读体验从来不属于我。

你应当拥有你写下的每一个字——包括它的排版、它的链接、它未来的去向。

所以有了这里。一个加载速度极快、没有任何追踪脚本、内容完全属于我自己的角落。

这座小站是怎么搭的

技术选型上我做了刻意的减法——零依赖的纯静态站点：

  • 没有框架、没有构建步骤：手写 HTML / CSS / JavaScript，浏览器打开即所得；
  • 文章数据一处维护：assets/js/posts.js 是唯一的数据源，列表、搜索、归档都由它驱动；
  • Git 管理一切：每个阶段都有独立提交，任何时候都可以回滚到历史版本；
  • GitHub Pages 托管：推送到 main 分支即自动部署，不花一分钱。

这个决定背后是一个朴素的判断：对于个人博客，能持续写十年 比技术栈先进重要得多。十年后 Node 生态可能换了天地，但 HTML 一定还在。

小站路线图

第一版先跑起来，之后打算按这个顺序慢慢迭代：

  1. ✅ 首页 / 文章列表 / 归档 / 关于页；
  2. ✅ 明暗双主题、全站搜索、标签筛选；
  3. 🔲 开启基于 GitHub Discussions 的评论（giscus）；
  4. 🔲 每月稳定输出 2 篇以上文章；
  5. 🔲 把这些年散落的笔记慢慢搬运回来。

如果你也想拥有一个自己的角落，这个仓库是公开的，欢迎 fork 去改成你的样子。 那么——你好，世界，我们正式认识了。
