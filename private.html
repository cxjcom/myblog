🛡️ 想让整个页面也上 Cloudflare Access 验证？看这里

当前这个页面的内容已用密码加密存在本机浏览器，别人打开也只会看到锁。但页面本身如果部署在 cxjcom.github.io，Cloudflare Access 罩不住它（GitHub 托管的域名，Cloudflare 无法在前面拦截）。想让它也过 Access 验证，需要三步：

  1. 准备一个自己的域名（任意注册商），把域名的 DNS 托管到 Cloudflare（免费计划即可）。
  2. GitHub Pages 绑定自定义域名：仓库 Settings → Pages → Custom domain 填入域名；Cloudflare DNS 里加 CNAME 指向 cxjcom.github.io 并开启橙色云代理；SSL/TLS 模式选 Full；仓库根目录放 CNAME 文件。
  3. Cloudflare Zero Trust → Access → Applications → 自托管应用：域名填你的博客，路径填 /private.html（想连后台一起保护就再加一条 /admin.html）；策略 Action=Allow，Include 选 Emails 填自己的邮箱，登录方式 One-time PIN。之后访问这个页面会先要求邮箱验证码。

详细图文见仓库根目录的 CLOUDFLARE-ACCESS.md。没配 Access 也没关系——手记内容始终是密码加密的，页面也未被任何地方链接。
